# Bilibili adapter

Private messaging, video search, metadata, per-part subtitles and Q&A, with
separate browser/evidence/comment workflows.

- [Platform notes](../docs/platforms.md#bilibili)
- [Configuration](../docs/configuration.md)
- [Upstream license](THIRD_PARTY_LICENSE.txt)

Use `python run_bilibili.py --help` for commands. Real account material belongs
in `private/accounts/bilibili/`; the local configuration selects that path.

B站的字幕阅读、音画分析、私信监听和评论互动是不同路径，分别配置和验收。
