# 微信实现目录

`adapter.py`：监听、消息归一化、微信客户端交互。

`tools.py`：微信工具定义和执行器。

`modules/`：微信专用文字回复、引用、撤回、群管理、媒体、拍一拍、朋友圈、OCR、语音转写和音频发送。

`run_wechat.py`、`run_moments.py`：启动实现。项目根目录的同名脚本保留兼容入口，启动命令不变。

原 `social_bot.wechat`、`social_bot.tools.wechat` 和已迁移模块导入路径保留兼容别名；实现只有此处一份。已有日志名称保持兼容。

DeepSeek 客户端、BotService、SQLite 存储及通用天气、搜索、时间、文件、链接、视觉处理仍在公共层。配置、凭据、图片及日志仍在项目目录。2026-11-01 已将本机微信历史迁移到 `E:/deepseek-chat-memory/wechat-default.sqlite3`，旧数据库保留；以根目录 `config.json` 的 `runtime.database_path` 为准。

`runtime.wechat_group_memory_enabled=true` 时，白名单群里由他人发送、实际被监听采集的消息也会入库，包括未 @、群未接通和冷却期间的消息；这些消息不会因此触发回复。全局范围开关关闭、非白名单、空消息和过长消息不会归档。自己消息仍保留原有防回环过滤。新记录保存发言人、正文、消息 ID 和数据库接收时间，旧记录缺失的发言人不补猜。群历史按会话隔离进入近期上下文，默认读取最近 12 条记录；尚无长期摘要或全库检索。

本次迁移包含机器人已有数据库，不包含微信客户端内从未被程序采集的历史，也不会遍历客户端聊天记录。图片和语音等仍按适配器提供的文本或占位符归档，未增加媒体原文记忆。

联测说明见项目根目录 `多端测试准备.md`，一键本地预检为 `python run_preflight.py`。
